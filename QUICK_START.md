# Quick Start Guide

Ready to start learning Go? Follow these steps to begin your journey!

## Step 1: Set Up Your Environment

1. **Install Go**: Download and install Go from [go.dev/dl/](https://go.dev/dl/)
2. **Verify Installation**: Open a terminal and run:
   ```bash
   go version
   ```
3. **Set Up Your Editor**: Install VS Code with the Go extension, or use your preferred IDE

## Step 2: Start with Topic 1

1. Navigate to the `01-basics` folder
2. Read the `README.md` to understand what you'll learn
3. Run the example program:
   ```bash
   cd 01-basics
   go run hello.go
   ```

## Step 3: Create Your First Learning Issue

1. Go to the **Issues** tab in this repository
2. Click **New Issue**
3. Choose **"Topic Learning Progress"** template
4. Title it: `Learning Progress: Go Basics`
5. Fill in your learning objectives for this topic
6. Save the issue

## Step 4: Start Learning!

Today's tasks:
- [ ] Read the 01-basics README
- [ ] Run the hello.go example
- [ ] Modify hello.go to experiment
- [ ] Write your own "variables.go" example
- [ ] Update your issue with today's progress

## Step 5: Daily Routine

**Each day:**
1. Open your topic issue
2. Review yesterday's progress
3. Set today's learning goal
4. Code for 30-60 minutes (or more!)
5. Update your issue with:
   - What you learned
   - Code you wrote
   - Any challenges
   - Resources you used

## Example First Day Entry

In your issue, add:


## Tips for Success

✅ **DO:**
- Code every day, even if just for 15 minutes
- Type out examples instead of copy-pasting
- Experiment and break things
- Document your learning in issues

❌ **DON'T:**
- Rush through topics
- Skip the exercises
- Just read without coding
- Compare your pace to others

## What's Next?

After completing a topic:
- Mark it complete in the main README checklist
- Move to the next folder
- Create a new issue for the new topic
- Optional: Build a small project using what you learned
